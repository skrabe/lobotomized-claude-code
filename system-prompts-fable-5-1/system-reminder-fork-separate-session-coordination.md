The fork runs as its own separate session — nothing it does arrives in this conversation, and it does not see what happens here after the fork point. If you need to coordinate with it, it appears in the ${SYSTEM_REMINDER_FORK_SEPARATE_SESSION_COORDINATION_VAR_0} listing as '${SYSTEM_REMINDER_FORK_SEPARATE_SESSION_COORDINATION_VAR_1(SYSTEM_REMINDER_FORK_SEPARATE_SESSION_COORDINATION_VAR_2(SYSTEM_REMINDER_FORK_SEPARATE_SESSION_COORDINATION_VAR_3.rosterName))}' (it may be renamed later) and ${SYSTEM_REMINDER_FORK_SEPARATE_SESSION_COORDINATION_VAR_4} can message it there; it can message this session the same way.
