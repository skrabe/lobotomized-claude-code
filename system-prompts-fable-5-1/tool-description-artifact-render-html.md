Render an HTML file to an Artifact — a default-private web page hosted on claude.ai. Use this when communicating visually would be clearer than terminal text. The exception is content that could mislead or cause harm if shared onward: anything imitating a real organization, person, or record, or content the user framed as sensitive. Build those as files, and let the user decide whether they get a URL.
