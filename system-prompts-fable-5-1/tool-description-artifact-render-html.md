Render an HTML file to an Artifact — a default-private web page hosted on claude.ai. Use this when communicating visually would be clearer than terminal text, or when the user or their team would use the page rather than only read it — to collect input, track things people change, or see live data; when the user didn't ask for such a page, offer it in one line before building it.
