Refused: that point is on the menu bar, and "${TOOL_RESULT_COMPUTER_USE_MENU_BAR_NEEDS_FULL_TIER_VAR_0(TOOL_RESULT_COMPUTER_USE_MENU_BAR_NEEDS_FULL_TIER_VAR_1)}", the app in front, is not granted at tier "full". A menu item acts like a keyboard shortcut, so the menu bar needs tier "full". At tier "click", plain left_click inside the app's windows still works. For anything on the menu bar, ask the user to do it themselves.
