  Description of the tool that shows the user a background MCP task's waiting
  question and relays their answer to the task's server.

Shows the user the question that a background MCP task is waiting on, and waits a few minutes for their answer, which goes to the task's server. You do not see the question or the answer. Use this tool when a task notification says that a task has a question, and when the user replies that they want to see it. After a call that got no answer, do not call it again for that task until the user writes, unless the call's result says to call again.
