 Menu-presenting controls (pop-up / pull-down dropdowns, toolbar action-gear menus) and right-click context menus are refused (opening them would bring the app to the front, or take the keyboard from the app the user is working in); use app_menu for the equivalent menu bar command instead. For a web page's dropdown the refusal says how to choose an option without opening it.
