a password field is aimed at or holds the keyboard focus, so this action is blocked. A person has to fill it in, in the app: say so in your reply, and never ask for the password itself. Do not take the screen for it. To work elsewhere in the window, move the keyboard focus out of it first with app_focus on the other element, then type or press there
