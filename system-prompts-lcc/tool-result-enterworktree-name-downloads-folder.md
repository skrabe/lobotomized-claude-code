Invalid worktree name "${TOOL_RESULT_ENTERWORKTREE_NAME_DOWNLOADS_FOLDER_VAR_0}": Claude Code keeps this name for its downloads folder. Choose another name. To reopen an existing worktree with this name, start Claude Code in that worktree's folder.
