Refused: that point is on the menu bar, and macOS did not say whose menus the bar shows. If the menus are those of an app granted at tier "full", click one of its windows on that display, take a screenshot, and try again. Otherwise, or if this keeps happening, ask the user to use the menu bar themselves.
