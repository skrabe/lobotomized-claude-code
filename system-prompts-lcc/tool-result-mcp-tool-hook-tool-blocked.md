<!--
name: 'Tool Result: MCP tool hook tool blocked'
description: Error when an mcp_tool hook targets an MCP tool that is blocked in the session
ccVersion: 2.1.322
variables:
  - TOOL_RESULT_MCP_TOOL_HOOK_TOOL_BLOCKED_VAR_0
  - TOOL_RESULT_MCP_TOOL_HOOK_TOOL_BLOCKED_VAR_1
-->
Hooks can't call '${TOOL_RESULT_MCP_TOOL_HOOK_TOOL_BLOCKED_VAR_0}' of MCP server '${TOOL_RESULT_MCP_TOOL_HOOK_TOOL_BLOCKED_VAR_1}', because that tool is blocked in this session. Remove this mcp_tool hook or point it at another tool.
