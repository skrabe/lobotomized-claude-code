Double-clicks in this file dialog's list are not allowed here: what is under this click cannot be read. To change folder, click it once in the folder list on the left, or use app_type with overwrite_existing: true on the "File name" box to enter a full path, starting with the drive. To pick a file, click its row once. Then click Open or Save. If that does not work, ask the user to finish this dialog.
