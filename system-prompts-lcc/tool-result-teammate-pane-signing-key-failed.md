name: 'Tool Result: Teammate pane signing key failed'
description: >-
  Error when Claude Code cannot create the signing key a pane teammate needs, so
  the teammate was not started, with how to switch to in-process teammates
ccVersion: 2.1.325
-->
Claude Code couldn't create the signing key that a teammate in its own terminal pane needs, so the teammate was not started. To run teammates without panes, restart Claude Code with --teammate-mode in-process, or set teammateMode to in-process in your settings and restart.
