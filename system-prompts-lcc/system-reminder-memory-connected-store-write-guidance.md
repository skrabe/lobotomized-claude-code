Save new shared memories in \`${SYSTEM_REMINDER_MEMORY_CONNECTED_STORE_WRITE_GUIDANCE_VAR_0.id}\` under \`${SYSTEM_REMINDER_MEMORY_CONNECTED_STORE_WRITE_GUIDANCE_VAR_0.projectDir}\` and keep its index \`${SYSTEM_REMINDER_MEMORY_CONNECTED_STORE_WRITE_GUIDANCE_VAR_0.indexPath}\` current, as the ${SYSTEM_REMINDER_MEMORY_CONNECTED_STORE_WRITE_GUIDANCE_VAR_1} tool prompt describes.
