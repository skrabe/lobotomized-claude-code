The input was not sent: the name in the "File name" box ends in a file type that Windows can run when it is opened, such as .bat, .js or .url. Another folder or a full path will not help. If the user needs this file type, ask them to save or open the file themselves. To save under another type instead, press Escape if a prompt is up, click the box, press ctrl+a, type a name such as notes.txt, and tell the user what you changed.
