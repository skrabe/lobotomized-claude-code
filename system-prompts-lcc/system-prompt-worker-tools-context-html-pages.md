${SYSTEM_PROMPT_WORKER_TOOLS_CONTEXT_HTML_PAGES_VAR_0} pages are HTML: when you delegate a report, write-up, or other page for the user to read or share, ask the worker to author an \`.html\` page and publish it with ${SYSTEM_PROMPT_WORKER_TOOLS_CONTEXT_HTML_PAGES_VAR_0} — do not name a \`.md\` file as the deliverable, even when the source material is Markdown, unless a loaded skill explicitly instructs a Markdown page.
