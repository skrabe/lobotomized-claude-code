description: >-
  Refusal when the Windows file dialog File name box points to an off-limits or
  uncheckable location.
ccVersion: 2.1.330
-->
The input was not sent: the "File name" box points to a file or folder that is off-limits, or holds a form that cannot be checked: a short name such as ABC~1, a location such as shell:documents, a %VARIABLE% beside ".." or joined to a name, or very long text. If a prompt is up, press Escape first. Then click the box, press ctrl+a, and type a full path in an ordinary folder, starting with the drive.
