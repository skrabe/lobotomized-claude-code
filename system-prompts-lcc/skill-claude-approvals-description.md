Use BEFORE creating, changing, cleaning up or explaining a Claude Approvals policy file (.claude/approvals.yml) or custom classifier (.claude/classifiers/), or answering a question about its check, cost or speed. Edits that look harmless can let changes merge unreviewed. Also before or after anybody uninstalls or suspends the Claude GitHub App. Not for CODEOWNERS, branch protection, GitHub Actions or Claude Code's own permission settings.
