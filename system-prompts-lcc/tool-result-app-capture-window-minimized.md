<!--
name: 'Tool Result: App capture window minimized'
description: >-
  Result when a minimized Windows window cannot be screenshotted in the
  background.
ccVersion: 2.1.330
-->
That window is minimized. Windows draws nothing for a minimized window, so it can't be screenshotted in the background. Ask the user to restore it (it can stay behind other windows), then retry.
