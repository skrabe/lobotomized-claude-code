Send this session’s work to a Claude Project: show the user the drafted brief on this tool’s own confirmation pane and, if they approve there, create the project (or use the one named by project_id), optionally add the folder’s GitHub origin as its repository, save the brief to project memory, post it as the project’s setup card, and tell the project which Remote Control session the work came from.
