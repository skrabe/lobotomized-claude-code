A draft REVIEW.md can be sent only with a pull request that is reviewed as it was merged, with no findings posted or applied, so nothing was launched. CLAUDE_CODE_ULTRAREVIEW_REVIEW_MD_FILE asked for a draft. Unset that variable to review without a REVIEW.md.
