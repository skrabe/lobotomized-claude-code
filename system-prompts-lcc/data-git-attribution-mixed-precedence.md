  organization-managed.

  - DATA_GIT_ATTRIBUTION_MIXED_PRECEDENCE_VAR_0
  - DATA_GIT_ATTRIBUTION_MIXED_PRECEDENCE_VAR_1

the ${DATA_GIT_ATTRIBUTION_MIXED_PRECEDENCE_VAR_0} line is set by the user's organization's managed settings and applies even if the user's instructions say otherwise; the user's own instructions about the ${DATA_GIT_ATTRIBUTION_MIXED_PRECEDENCE_VAR_1} line, such as a CLAUDE.md or memory rule, take precedence, but do not add attribution lines this reminder leaves out
