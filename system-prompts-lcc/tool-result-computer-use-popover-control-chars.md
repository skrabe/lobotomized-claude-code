description: Refusal for typed control characters while a popover text field has focus.
ccVersion: 2.1.330
-->
Typed text that holds a tab, a newline or another control character is not available while a popover's text field has the keyboard focus: it would commit the field before it can be checked. Type the text without it, then press the key with a key call.
