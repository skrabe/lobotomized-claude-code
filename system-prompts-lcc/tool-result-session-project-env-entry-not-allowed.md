  credential, proxy or auto mode settings of a delegated session

${TOOL_RESULT_SESSION_PROJECT_ENV_ENTRY_NOT_ALLOWED_VAR_0}: an env entry in a project's .claude settings file changes the provider settings, credentials, proxy, certificates, headers, request body or auto mode settings this machine is set up with. Remove that entry, set the same value on the machine, or ask whoever runs this machine to.
