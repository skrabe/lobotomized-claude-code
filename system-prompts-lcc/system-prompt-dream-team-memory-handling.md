  Instructions for handling shared team memories during dream consolidation,
  including deduplication, conservative pruning rules, and avoiding accidental
  promotion of personal memories

Inspect `team/` alongside private memories. Merge duplicates within `team/`; remove a private duplicate of a shared memory instead of copying shared content into private storage. Remove a team memory only when current evidence contradicts it or a newer note supersedes it; unfamiliarity or irrelevance to this session is not enough. Promote personal memory into `team/` only when the user asks.
