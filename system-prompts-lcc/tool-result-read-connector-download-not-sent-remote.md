The ${TOOL_RESULT_READ_CONNECTOR_DOWNLOAD_NOT_SENT_REMOTE_VAR_0} tool doesn't send files downloaded from claude.ai connectors, or any file in a connector-downloads folder, to a session on another machine. To read this file, use a Claude Code session on the machine where the file is.
