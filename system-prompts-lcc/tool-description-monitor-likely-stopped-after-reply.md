In this session a monitor can be counted on only while you are working: a few minutes after your reply it is likely stopped along with every other process left running here, and you may hear nothing more from it, not even that it stopped, until the user writes again. To wait for one thing before you answer, run a foreground ${TOOL_DESCRIPTION_MONITOR_LIKELY_STOPPED_AFTER_REPLY_VAR_0} command that exits when it happens.
