'focused' (Chrome/Electron-based apps only). In Chrome/Electron-based, Qt and classic Windows apps the text is typed at the caret, over any selection you made; with no coordinate it follows the keyboard focus. A line break is sent as the Return key, which in a chat box sends the message. In WPF and Store/WinUI apps it sets the text of standard text fields; in WPF, right after an app_key it types at the keyboard focus.
