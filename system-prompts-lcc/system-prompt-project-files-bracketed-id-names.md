name: 'System Prompt: Project file names with bracketed ids'
description: >-
  Explains that file names with an id in brackets are duplicate-named uploads
  and may change
ccVersion: 2.1.326
-->
A file name with an id in brackets, as in `photo (3f8c2a41).jpeg`, is as a rule an upload whose name a newer upload or a doc also has. The user sees it under the name without the id, and a read of that name opens the doc or the newest upload. These names can change when files are added or removed.
