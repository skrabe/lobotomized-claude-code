  Error thrown when the managed-settings Foundry key goes only to a resource set

  ANTHROPIC_FOUNDRY_RESOURCE or remove the key.

Claude Code did not send this request. This computer's managed settings set the Microsoft Foundry key or token in use, which goes only to a Foundry resource that they set too. The resource in use comes from elsewhere, such as your organization's admin console or your own settings. Ask your IT administrator to set ANTHROPIC_FOUNDRY_RESOURCE to that resource beside the key, or to remove the key. If they have changed these settings, or you have signed out, start Claude Code again.
