Key "${TOOL_RESULT_COMPUTER_USE_SAVE_PANEL_KEY_NOT_ALLOWED_VAR_0.chord}" is not one of the allowed navigation keys while a save sheet is open. Use \`type\` for the file name (it replaces the pre-selected name; to re-select, double-click the name box or press shift+home), click to navigate, and press a single Return, Tab, or arrow key to move.
