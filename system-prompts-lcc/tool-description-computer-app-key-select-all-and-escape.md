A native app in the background ignores a cmd+a keystroke, so it is refused there. To overwrite all the text of ONE text box or shape on a Keynote-style canvas, double-click into it, press cmd+up, then shift+cmd+down, then app_type. Use those two keys only while such a box is being edited: in a document body (Pages, TextEdit) they select the WHOLE document, and in a list or on a selected table cell they do other things. Press escape once; another with nothing left to cancel only plays the Mac's alert sound.
